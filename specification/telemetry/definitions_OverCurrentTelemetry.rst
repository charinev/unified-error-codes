.. _Telemetry_OverCurrent_Location:

************************
 OverCurrent Location
************************
-  **Description**: The location of the over current condition. 
-  **Values**: EVSE, EV, unknown
-  **Unit**: N/A
-  **Resolution**: N/A

.. _Telemetry_OverCurrent_ActualCurrent:

***********************
 Actual Current
***********************

-  **Description**: The actual current measured at the over current location at the time of the over current condition.
-  **Values**: Any positive numeric value representing the current in amperes.
-  **Unit**: Amperes (A)
-  **Resolution**: 0.1 A

.. _Telemetry_OverCurrent_ThresholdCurrent:

***********************
 Threshold Current
***********************

-  **Description**: The threshold current defined by the EVSE or EV that triggers the over current condition.
-  **Values**: Any positive numeric value representing the current in amperes.
-  **Unit**: Amperes (A)
-  **Resolution**: 0.1 A
